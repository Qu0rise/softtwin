# モデルカード

学習したモデルは 3 つで、どれも numpy だけで推論でき、重みは JSON で `learning/` に置いてある。GPU も深層学習のフレームワークも要らない。
評価の数字は `results/metrics.json` と README にある。

## 1. 筋肉のモデル（`learning/actuator_net.json`、比較用に `actuator_greybox.json`）

| 項目 | 内容 |
| --- | --- |
| 役割 | 測った内圧から指の自由曲げを予測する。固有感覚の力推定（予測と実測の差）の基準になる |
| 入力 | $[\tilde p_k,\ \dot{\tilde p}_k,\ \hat\theta_{k-1}]$。内圧は時定数 40 ms で前処理（センサ雑音が微分で増えるのを抑える） |
| 出力 | 指 1 本の自由曲げ [deg]。0 未満は 0 |
| 構造 | 3-48-48-1、tanh。自己回帰で使う |
| 学習データ | 100 軌道 × 20 s × 50 Hz。段差・ランプ・正弦と、把持に似た内圧（速い増圧、接触後を模した 1〜5 kPa/s の増圧、修正を含む保持、排気）の 4 種。模擬筋肉（不感帯 6 kPa、飽和、時定数 0.12 s、遊び要素で表した幅 6° の履歴）の**合成データ**で、内圧に 0.2 kPa、曲げに 0.6° の雑音を加えた。接触後のゆっくりした増圧を入れないと、把持中の自由曲げを約 2° 大きく見積もった |
| 分割 | 軌道単位（同じ軌道の前後が学習と評価に分かれない） |
| 評価 | 評価用の軌道を自己回帰で回したときの RMSE（`results/actuator_identification.json`）。直線モデルとグレーボックスも同じデータで同定した |
| 既知の限界 | 実機のログで学習していない。温度や疲労による特性の変化は入っていない。模擬筋肉は構造が既知なので、同じ構造のグレーボックスで足りる |
| 更新 | `python learning/actuator_net.py --csv <内圧と曲げの CSV>`（M5Stack のファームウェアが同じ列で書く） |

## 2. 取扱い区分の分類器（`learning/tactile_classifier.json`）

| 項目 | 内容 |
| --- | --- |
| 役割 | 把持の前に区分（very_fragile、soft、fragile、sturdy）を決め、取扱い表から $F^*$ を引く |
| 入力 | 画像 5 次元（平均色 3、面積、縦横比）＋プランジャ 3 次元（傾き $k_p$、上面の高さ、押し込み量）。比較用に、画像のみ、画像＋指プローブ 10 次元、すべての組も学習した |
| 構造 | 多クラスロジスティック回帰（L2 = 0.01） |
| 学習データ | 自動アノテーション付きデータ 420 試行（7 物体 × 60、シード 1000 以降）。評価のシード（0–29）とは重ならない |
| 評価 | 区分で層化した 5 分割交差検証と、Q2 の閉ループ評価 |
| 間違えやすい所 | 豆腐と過熟中玉トマトは、プランジャの傾きがほぼ同じ（どちらも約 0.22 N/mm）で、許容力は違う（4.0 N と 2.0 N）。これを分けているのは画像（色と形）である。硬さだけでは壊れやすさは決まらない |
| 既知の限界 | 区分は学習データにある物体の分け方そのもの。新しい種類の物体は、既存の区分のどれかに押し込まれる |

小さな線形モデルにした理由：特徴を物理の意味がある 8 つに絞ったので、非線形にする利点が小さい。重みを見れば、どの特徴が効いているかを確かめられる。

## 3. 力の窓（`learning/force_window.json`、物体を 1 つずつ除いたもの `force_window_loo.json`）

| 項目 | 内容 |
| --- | --- |
| 役割 | 区分を経由せずに $F^*$ を決める。潰れる確率と滑る確率がどちらも低い力を選ぶ |
| 入力 | 分類器と同じ 8 次元 $x$ と、候補の力 $F$ |
| 出力 | $p(\text{潰れ}\mid x,F)$、$p(\text{滑り}\mid x,F)$。$F^*=\arg\min_F\,p(\text{潰れ})+p(\text{滑り})$ |
| 構造 | 2 つのロジスティック回帰（特徴 $[z, F, zF]$、$z$ は正規化した $x$、L2 = 0.003）。推論時に「強く握るほど潰れやすく、滑りにくい」という単調性に射影する |
| 学習データ | 分類器と同じ。ラベルは自動アノテーションの「破損」と「滑り・落下」だけ（区分も取扱い表も使わない） |
| つかみ直し | 滑ったら、$p(\text{潰れ})<0.2$ の範囲で $p(\text{滑り})$ が最小の力に上げる |
| 既知の限界 | 学習データの目標力は 0.5〜4.0 N の一様乱数で、許容力の幅が狭い過熟の物体では、成功した例が少ない。見たことのない物体の許容力は、硬さからは推せない |

## 共通の注意

- すべてシミュレーションのデータで学習している。果実の柔らかさは接触剛性の近似で、許容力は卵以外は仮定値である。
- 実機に移すときは、筋肉のモデルを実機のログで学習し直してから、分類器と力の窓のデータを取り直す。力の推定が筋肉のモデルに依存していて、ほかの 2 つの入力も変わるからである。
