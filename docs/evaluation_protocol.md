# 評価の数え方

結果の数字はすべて `results/metrics.json` にあり、README と説明資料はそこから自動で書き出している（`scripts/make_numbers.py`）。
このページには、何をどう数えたかだけを書く。

## 1. 問いと比べるもの

| | 問い | 比べるもの |
| --- | --- | --- |
| Q1 | 力センサなしで、潰さず落とさない力で握れるか | 開ループ（区分ごとの内圧表）、閉ループ × 筋肉のモデル 4 種（直線・静特性の表・グレーボックス・学習）、作用点を指先に固定した推定、真の力で帰還 |
| Q2 | 見た目が同じで硬さだけが違う物体を、把持の前に見分けられるか | 目標把持力の決め方 8 通り（3 節） |
| Q3 | 学習データを人手なしで作れるか | 生成時間、検証器の違反数、区分の正解率（5 分割交差検証） |
| 確認 | エンジンを替えても、筋肉と指がずれても成り立つか | PhysX での Q1、筋肉の定数と $k_b$ のずれ |

## 2. 物体と乱数化

物体の数値と根拠は [physical_parameters.md](physical_parameters.md)。
基本 5 物体は、いちご・卵・木綿豆腐・中玉トマト・ボルト。見た目が同じ 2 物体は、過熟中玉トマトと過熟いちごで、見た目（形・大きさ・色）と質量・摩擦は熟した方と同じにした。
試行ごとに、質量 ±15 %、摩擦 ±20 %、接触剛性 ±20 %、置き場所（6 か所から 1 つを選び ±15 mm）、向き（楕円体と直方体のみ 0〜120°）を、乱数の種 `[seed, crc32(物体名)]` から決める。

## 3. 目標把持力の決め方（Q2）

| 名前 | $F^*$ の決め方 | つかみ直しの上限 |
| --- | --- | --- |
| `visual_prior` 見た目だけ | 見た目の区分 → 取扱い表 | 見た目の区分の許容力 × 0.8 |
| `soft_start` 弱く握り始める | すべて 1.0 N から。滑ったら ×1.3 | 同上 |
| `finger_clf` 指で触る | 0.8 N まで弱く握り、画像＋指の特徴で区分を決める | 判断した区分の許容力 × 0.8 |
| `plunger_clf` プランジャ（**提案**） | 把持の前に 0.3 N まで押し、画像＋プランジャの特徴で区分を決める。握る高さも決め直す | 同上 |
| `plunger_clf_tip` | 同上、ただし力の推定で作用点を指先に固定（比較用） | 同上 |
| `force_window` 力の窓 | 区分を使わず、$p(\text{潰れ}\mid x,F)+p(\text{滑り}\mid x,F)$ を最小にする $F$ | $p(\text{潰れ})<0.2$ の範囲 |
| `force_window_loo` | 力の窓を、その物体を除いたデータで学習したもの | 同上 |
| `oracle` 正解の区分 | 真の区分 → 取扱い表（プランジャなし） | 真の区分の許容力 × 0.8 |

取扱い表（ラインの仕様として与える）：very_fragile 1.0 N（許容 1.5 N）、soft 1.55 N（2.0 N）、fragile 2.2 N（3.0 N）、sturdy 3.0 N（25 N）。
提案を `plunger_clf` とし、要求 R5・R6 をこれで判定することは、最後の 30 シードを回す前に決めた。

## 4. 成否

| ラベル | 定義 |
| --- | --- |
| 破損 | 保持中（把持〜載置）の真の把持力の 60 ms 移動平均の最大値 > その物体の許容力。つかみ直しの分も含める |
| 滑り | 持ち上げの後、物体が卓上 8 cm より下に残った（つかみ直しの対象） |
| 落下 | 持ち上げた後、搬送か載置のあいだに 0.1 s 以上どの指にも触れていない |
| 成功 | 持ち上げ、トレーの範囲に置け、破損がない |

つかみ直しは最大 3 回。4 回とも持ち上がらなければ「滑り」で終わる。
ラベルはシミュレータの真値から機械的に決まり、人の判断は入らない。

## 6. 統計

- 比率の 95 % 信頼区間は Wilson の方法。0 や 1 に近い比率でも正規近似のように崩れない。
- 各方式は同じ（物体、シード）の試行を走るので、2 方式の比較は対応のある McNemar の正確検定（不一致の組だけの二項検定）にした。差の 95 % 信頼区間は Newcombe（1998）の方法 10 で求めた。
- 事前に決めた比較（`analysis_stats.py` の `fam1`、`fam2`、PhysX の 3 つ）に、まとめて Holm の補正をかけた。
- 区分の分類は、区分で層化した 5 分割交差検証。1 試行が 1 個体なので、試行の単位で分けても同じ個体が学習と評価にまたがらない。

## 7. 要求

| | 要求 | 目標 |
| --- | --- | --- |
| R1 | 筋肉のモデルの曲げ角 RMSE（評価用の軌道、自己回帰） | ≤ 3° |
| R2 | 接触中の把持力推定の平均絶対誤差（学習モデル） | ≤ 0.2 N |
| R3 | 基本 5 物体の成功率 | ≥ 90 % |
| R4 | 基本 5 物体の破損率（信頼区間の上端） | ≤ 5 % |
| R5 | 見た目が同じ物体の成功率（`plunger_clf`） | ≥ 85 % |
| R6 | 全 7 物体の破損率（信頼区間の上端、`plunger_clf`） | ≤ 5 % |
| R7 | 画像＋プランジャの区分の正解率（5 分割交差検証） | ≥ 95 % |
| R8 | 筋肉が ±20 % ずれても、空中較正ありで成功率 | ≥ 90 % |

判定は `metrics.json` の `requirements`。R4 と R6 は点推定ではなく区間の上端で判定する（試行が少ないと上端は下がらないので、厳しい側の判定になる）。

## 8. 決定性

同じシードの試行は、同じ環境（`requirements.txt` の版）でビット単位まで同じ結果になる。
`scripts/check_determinism.py` は、シード 0–1 を走らせ直して公開した行と比べる。テスト（`tests/test_core.py`）でも 1 行を比べている。

## 9. 判別マップ（`scripts/probe_sensitivity.py`）

過熟の剛性を、熟した方の 1/1〜1/4 に振る。各点 30 個体で、雑音なしのセンサで指プローブとプランジャを走らせ、真値の時系列を保存する。
そのあと雑音を後から 5 回足し、1 次元の特徴（指：曲げとスキンの力の傾き、プランジャ：荷重と変位の傾き）を計算する。
しきい値 1 つの分類器を 5 分割交差検証し、その正解率を 1 点の値にする。雑音のモデルは閉ループのものと同じである。
