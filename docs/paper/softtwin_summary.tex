\begin{multicols*}{4}
\hd{問題と問い}
{\small 過熟の中玉トマトは，カメラには普通のトマトに見える．硬さは画像に映らず，指に力センサはない．
\begin{itemize}
\item \textbf{Q1} 力センサなしで，潰さず落とさない力で握れるか
\item \textbf{Q2} 見た目が同じ物体を，握る前に見分けられるか．指で触るだけで足りるか
\item \textbf{Q3} 人手のラベル付けなしで，判断の学習に使えるデータを作れるか
\end{itemize}\par}

\hd{仕組み}
{\small\raggedright
\begin{enumerate}
\item \textbf{共有する制御コア}：個体・筋肉・センサ・推定・制御・成否の判定を一つにまとめ，MuJoCo と PhysX は動力学だけを受け持つ
\item \textbf{物理を文献値に}：熟したトマト 1.5，過熟 0.6\,N/mm（文献のレッド 1.16〜緑熟 3.58\,N/mm から設定）．接触剛性を測って合わせ込み，目標との差を \V{cal.mj.maxdev} 以内にした
\item \textbf{作用点を触覚で補う推定}：$\hat F_f=k_b\Delta\theta_f/\bar\Lambda_f$．$\bar\Lambda_f$ はスキンの出力で重み付けたてこの和
\item \textbf{硬さプランジャ}：直径 8\,mm の平型先端で 0.3\,N まで押し，傾き $k_p$ を測る．画像と合わせて取扱い区分（極脆・軟・脆・頑丈）を決める
\end{enumerate}\par}

\columnbreak
\hd{Q1：力センサなしで握る}
\includegraphics[width=\linewidth]{poster_q1.png}\par
{\footnotesize\color{sub}\sq{ok} 成功　\sq{drop} 滑り・落下　\sq{crit} 破損．ひげは Wilson 95\,\% 区間．\par}\par
{\small 直線の筋肉モデルはいちごを全数潰す．履歴を持たないグレーボックスは力を 1 割以上大きく見積もって弱く握り，豆腐を落とす．力の推定誤差は \V{q1.learned.mae}\,N．\par}


\hd{エンジンを替えても}
{\small 制御コアはそのまま，動力学だけを PhysX に替えた（各方式 $n=\V{px.n}$）．学習モデルの閉ループは \V{px.learned.succ}\,\%・破損 \V{px.learned.cr}．直線モデルの成否は同じ個体で \V{s2s.affine.same} 一致し（$\kappa_{\mathrm C}=\V{s2s.affine.kappa}$），いちごを PhysX でも全数潰した．同じ個体を両エンジンで突き合わせられるので，差の出どころ（豆腐の角の接触，搬送の加減速）まで追える．\par}

\par\vspace{0.6mm}
\includegraphics[width=\linewidth]{poster_q2.png}\par
{\small 失敗 \V{fail.plunger.n} 件は，正解の区分を与えても同じ試行で起きる落下だった．判断の誤りは 0 件で，残りは握り方（重い過熟トマト，指のあいだから抜ける過熟いちご）．目標の 85\,\% には未達．重さから目標の下限を上げると，開発に使っていないシードで \V{ho.q2.mass.la}\,\%（破損 0）．\par}

\columnbreak
\hd{大きさが変わったら}
{\small 内圧表（開ループ）は，調整に使った大きさなら基本 5 物体で \V{q1.recipe.succ}\,\% と強い．寸法 1.2 倍では過熟トマトを \V{ss.recipe.1.2.tomato_overripe.cr} 回潰した．閉ループは潰さないが，重くなった物を落とす．大きくなって変わるのは「落とさない力の下限」で，1.2 倍の過熟トマトに要る \V{ss.mass.Fmin.tomato_overripe.1.2}\,N は許容力 2.0\,N を超える．\par}

\hd{Q3：データ}
