# 実機に移すときの見通し

評価はすべてシミュレーションである。何が仮定で、実機で何が崩れそうかを先に見積もっておく。

## 1. 仮定の一覧

| 要素 | シミュレーションでの扱い | 実機で置き換えるもの |
| --- | --- | --- |
| 人工筋肉 | 模擬筋肉（不感帯・飽和・遅れ・履歴を持つモデル）がプラントで、制御側は筋肉のモデルだけを知る | M5Stack の内圧と曲げのログで学習し直したモデル。同定の入力には、力の閉ループが接触後に出すゆっくりした増圧を必ず入れる |
| 指 | 剛体 4 節＋関節のばね（$k_b$ = 0.5 N·m/rad） | シリコーンの指。$k_b$ はロードセルを押して同定する |
| 果実 | 剛体の外形＋接触の柔らかさ（N/mm、文献値） | 実物 |
| 許容力 | 卵は文献値の約 6 割、ほかは仮定 | 実物で、押し込みと傷みの関係を測る |
| センサ | 雑音・遅れ・量子化・漏れを持つモデル（[physical_parameters.md](physical_parameters.md)） | 実物。特性を測って `SensorSpec` の定数を合わせる |
| 物体の位置 | シミュレーションの真値 | 手先カメラの検出 |

## 2. 崩れそうな所と手当て

### 2.1 指の曲げ剛性 $k_b$

力の推定は $k_b$ に比例する。$k_b$ が 25 % ずれると把持力も 25 % ずれ、いちごでは許容力に届いた（`results/robustness.json`）。
空中較正では、$k_b$ は見えない。実機では、掌の下に小さなロードセルを置いて指で押し、推定値と比べて $k_b$ を決める（数分の作業）。

### 2.2 プランジャの傾きは、台との接触も含む

果実を台に置いて上から押すと、プランジャ側と台側の両方で果実がへこむ。測った傾きは 2 つの直列で、指 1 本の接触剛性とは一致しない（シミュレーションでも同じで、熟した中玉トマトで約 0.5 N/mm）。
判断に使うのは同じ条件で測った値どうしの比較なので、問題にはならない。ただし、台の材質（柔らかいトレー）が変わると値も変わるので、台は固定する。

### 2.3 指で触るだけで見分けるのは難しい

指先のコンプライアンス（0.041 m/N）は果実の 16〜61 倍あり、果実のへこみは指のたわみに埋もれる（判別マップ）。
実機でも、指で触る方式は主にしない。プランジャを主にし、指のスキンは接触の判定と作用点に使う。

### 2.4 作用点

スキンの出力の分布は、隣の点への漏れ（10 %）と不感帯（0.08 N）で少しずれる。指先の接触はスキンの最も先の点より先にあるので、てこの和を約 5 % 小さく見積もる。シミュレーションではこのずれを含めて推定誤差が下がった。
実機の布スキンは、貼り方で漏れが変わる。まず指先から根元へ既知の力を当て、各点の実効的な位置を較正する。

## 3. 移す手順

| 段階 | やること | 合格の目安 |
| --- | --- | --- |
| 1 | M5Stack で内圧と曲げを 50 Hz で記録（`firmware/`）。段差・ランプ・正弦・把持に似た指令を 20 s ずつ | 100 軌道 |
| 2 | 筋肉のモデルを学習し直す（`learning/actuator_net.py --csv`）。グレーボックスも同定して比べる | 自己回帰 RMSE ≤ 3°（R1） |
| 3 | ロードセルを押して $k_b$ を決め、スキンの各点の位置を較正する | 力の推定の平均絶対誤差 ≤ 0.2 N（R2） |
| 4 | 実物で押し込みのデータを取る。熟度の違う中玉トマトといちご各 20 個、豆腐 | 区分の交差検証 ≥ 95 %（R7） |
| 5 | 同じ評価の手順（[evaluation_protocol.md](evaluation_protocol.md)）を、試行数を減らして実機で回す | R3–R6 |

段階 3 が通らないうちは段階 4 に進まない。力の推定は筋肉のモデルと $k_b$ に依存しているので、ここがずれたままだと後の全部がずれる。

## 4. 部品

| 部品 | 用途 | 備考 |
| --- | --- | --- |
| M5Stack（ESP32） | 制御と計測、micro-ROS（Wi-Fi） | `firmware/m5stack_softgripper` |
| 12 V ダイアフラムポンプ、3/2 電磁弁 | 加圧と排気 | MOSFET で駆動 |
| アナログ圧力センサ | 筋肉の内圧 | 0–100 kPa |
| 曲げセンサ（または指先の IMU） | 指ごとの曲げ | 3 本 |
| 布状の圧抵抗スキン | 接触の判定と作用点 | 24 点、指の内側 |
| 小型リニアアクチュエータ＋ロードセル＋エンコーダ | 硬さプランジャ | 直径 8 mm の平型先端。掌から果実の上面まで約 6 cm 伸ばすので、ストロークは 8 cm 程度 |
| シリコーンの指（3 本） | 把持 | PneuNets 型の空気室（Mosadegh ら 2014）を型取りで作る |
